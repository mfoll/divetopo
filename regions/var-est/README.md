# Var Est

Var Est is an autonomous DiveTopo region covering the Estérel coast around
Saint-Raphaël, Le Dramont, Anthéor and Le Trayas. It is not a PACA subregion.

- Regional contract: [`region.json`](region.json)
- Mapping and integration procedure: [`WORKFLOW.md`](WORKFLOW.md)
- Current regional QA: [`QA.md`](QA.md)
- Site configurations: `sites/`
- Canonical generated outputs: `outputs/`
- Interactive terrain packages: `outputs/interactive-terrain/`
- Conceptual public route: `/var-est`

The first-wave inventory contains exactly five sites: Les Pyramides, Sec de
l’Île d’Or, Arche du Dramont, Cathédrale du Trayas, and Le Village. They remain
unpublished until regional-map, marker, desktop/mobile, and manifest QA have
passed and publication has been approved explicitly.

The regional-map paths are reserved, but the image is intentionally absent
until the globally coordinated shared regional builder is integrated.
