# Var Est

Var Est is an autonomous DiveTopo region covering the Estérel coast around
Saint-Raphaël, Le Dramont, Anthéor and Le Trayas. It is not a PACA subregion.

- Regional contract: [`region.json`](region.json)
- Mapping and integration procedure: [`WORKFLOW.md`](WORKFLOW.md)
- Site configurations: `sites/`
- Canonical generated outputs: `outputs/`
- Interactive terrain packages: `outputs/interactive-terrain/`
- Conceptual public route: `/var-est`

The initial regional inventory is deliberately empty. Site commits are
integrated separately, and every new site remains unpublished until regional
map, marker, desktop/mobile and manifest QA have passed and publication has
been approved explicitly.
