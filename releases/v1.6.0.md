# DiveTopo v1.6.0

## New dive sites

Côte Bleue is now available from the DiveTopo homepage in French and English.

- Tombant de Méjean
- Tombant de l’Érevine
- Les Yeux de Chat
- Les Jardins de Sausset

Each site has topographic and aerial 2D maps, interactive 3D terrain, and an annotated A4 PDF for printing. The regional page includes a coastline relief map for choosing a site and a map showing Côte Bleue within metropolitan France.

The homepage uses consistent thumbnail dimensions and feature labels across regions.
