# DiveTopo v1.7.1

## Interactive terrain

The 3D viewer opens with the classic contour style. The new depth-label icon switches to draped contours and labels at the current view.

## Côte Bleue print sheets

Seven sites now use the standard DiveTopo layout for A4 print sheets. Both the topographic and aerial sheets show an annotated 2D map, a classic 3D view, coordinates, and a location map.

- Tombant de Méjean
- Tombant de l’Érevine
- Les Yeux de Chat
- Les Jardins de Sausset
- Les Jonquiers
- Le Moulon
- Le Cap Frapaou
