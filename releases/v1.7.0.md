# DiveTopo v1.7.0

## New dive sites

- Les Jonquiers
- Le Moulon
- Le Cap Frapaou

Each site has topographic and aerial 2D maps, interactive 3D terrain, and an annotated A4 PDF. The Côte Bleue locator now shows seven sites, with reorganized labels and connecting lines.

The Cap Frapaou map marks the limits of the measured bathymetry. The Moulon model represents the surveyed terrain around the arch.
